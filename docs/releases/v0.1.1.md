# 星匣 v0.1.1

电脑版 EXE 和 Android APK 首次启用 GitHub 在线更新，独立于旅人手札。

- 程序设置中检查版本、下载并确认安装，启动时自动检查。
- GitHub 与镜像备用线路，发布签名、文件哈希及安装包身份验证。
- 修复电脑端在本机构建目录中需要管理员运行的问题。
- 保留个人资料、本机互通、19 种标准模板、自定义字段与来源原文。
- 源码附维护 skill、功能表和使用说明；代码由 AI 辅助编写。

**旧 v0.1.0 原型需要先手动安装本版一次**，以后可使用程序内更新。Android 覆盖安装即可，勿先卸载；Windows 解压新版运行，共用原来的个人资料目录。

Windows 已有 WebView2 可用 Light 包，缺少运行环境请选 Full 包。APK 支持 Android 8.0 及以上。

个人飞书资料及图片不随公开包发布。镜像可用性因网络而异；可在更新设置中换线路。未在实体手机完成现场验收。
