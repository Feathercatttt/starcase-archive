# 星匣 · 创作档案 v0.1.2

**AI 辅助编写的个人跑团创作工具。当前为早期版本，请定期导出备份；规则内容以使用者原文与裁定为准。**

[Windows 电脑版](https://github.com/Feathercatttt/starcase-archive/releases/latest/download/Starcase-Windows-Update.zip) · [Android APK](https://github.com/Feathercatttt/starcase-archive/releases/latest/download/Starcase-Android.apk) · [离线 HTML](https://github.com/Feathercatttt/starcase-archive/releases/latest/download/Starcase.html) · [全部版本](https://github.com/Feathercatttt/starcase-archive/releases)

一个独立于旅人手札的个人创作资料库。这是供审阅模板和操作方式的首版，暂不区分主持人、玩家或剧透权限。

## 打开

- Windows：完整解压下载的 ZIP，打开 `Starcase-Update` 文件夹中的 `星匣.exe`。此包既可首次使用，也用于程序内更新。需要 Microsoft Edge WebView2；缺少时按程序提示，或从 [微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装环境。
- 电脑版按普通双击方式运行，不需要勾选“以管理员身份运行”。请先解压，再打开 EXE。
- Android：安装 `星匣-Android.apk`，应用名称为“星匣”。它与旅人手札使用不同的包名和数据目录，可以同时安装。
- 网页预览：直接打开 `星匣.html`，不联网也能编辑与保存。浏览器版本的数据保存在该浏览器中，扫码服务由 EXE 提供。

## 四个分区

| 分区 | 初版功能 |
| --- | --- |
| 灵感盒 | 一两句话快速入库、标签、DND / COC / 通用、收藏、待整理 / 酝酿中 / 已落地；转成正式条目时保留原文关联 |
| 世界观 | 地点、人物、势力、植物、设定 / 历史、自由条目；按世界分组 |
| COC 模组 | 模组总览、场景、线索、人物、时间线、线索道具、结局；按模组分组 |
| 规则与资料 | 私设规则、DND 魔法物品与怪物、COC 物品与怪异、自由资料条目 |

原文附图可在阅读页展开查看；单条分发会带走该条目的立绘与附图，完整备份保留所有图片。

每条档案可编辑摘要、标签、别名、图片、类型字段、自定义字段、关联档案和原文来源。空字段在阅读界面隐藏，编辑时按组展开。自定义字段支持短文字、长文字、数字 / 公式、是 / 否和列表。

首屏的故事内容都标记为“示例内容”，可自由改写，不是已确认的房规。新建资料不带示例标记。

## 灵感怎么用

先在首页写一句话，标签可稍后补。电脑可以按 Ctrl+Enter 收纳。

打开灵感，点击“落地为条目”，选择地点、规则、场景等模板。保存后新条目与原灵感保持关联，灵感转为已落地；取消创建不会改变原灵感。

## 自己的资料

在“设置与资料互通 → 导入资料包”打开星匣 JSON 文件，先预览再确认。条目可保留来源 URL、修订号、读取时间、完整原文和校对状态。没有提供的怪物属性不会推定为 0。植物归入世界观。

个人资料、飞书原文、图片及密钥不包含在公开程序或源码包中。软件不会自动读取你的飞书账户或上传资料到 GitHub。

## 电脑 ↔ 手机互通

1. 两端连接同一 Wi-Fi。
2. 电脑 EXE：设置与资料互通 → 电脑与手机互通 → 开启扫码互通。
3. 手机 APK：进入同一入口，选“扫描并接收电脑资料”或“扫描并发送本次资料”，由应用打开相机。
4. 接收后先预览，选择保留较新内容、使用文件中的内容，或导入为副本。

也能用资料文件互通。挑选条目分发支持只带走特定规则、物品、怪物或模组片段；图片会随选中条目带走。没有一并选择的关联仍保留标识。

一次传送 / 导出上限 32 MB，单张图片上限 8 MB；较大的库可以挑选条目分批带走。二维码 20 分钟到期，关闭互通窗口结束分享。首次网络连接可能需要在电脑防火墙中允许局域网访问；连接受限时可用文件互通。

## 保存与恢复

- Windows 本机资料：`%LOCALAPPDATA%\StarcaseArchive\library.json`。
- Windows 后台自动备份：同目录 `backups`，最近 10 份。
- 手机与网页：独立 IndexedDB 数据库，APK 覆盖升级会保留数据。
- 导入、删除和恢复前，会另留最近 10 个应用内恢复点，在设置中可查看。

编辑框要点击“保存条目”才提交，取消不改动原记录。灵感快速输入框会保留未提交的文字。卸载 APK 或清除浏览器数据前，应先导出资料。

## 更新方式

已移植手札的镜像切换、发布签名验证、文件哈希校验和确认安装流程，并使用星匣自己的更新密钥及 Android 签名。

v0.1.1 起启用独立仓库 [Feathercatttt/starcase-archive](https://github.com/Feathercatttt/starcase-archive)。进入“设置与资料互通 → 程序更新”，检查、下载后点击“确认安装”；也会在启动时检查版本。只有程序和版本清单会联网，个人资料继续留在本机。

旧 v0.1.0 原型没有启用更新按钮，需要先从本页手动安装一次 v0.1.1 或更高版本。Android 直接覆盖安装，保留资料；Windows 解压新版使用同一用户资料目录，保留旧包作备份。不要卸载 APK 或删除用户资料目录。

默认自动尝试 GitHub 与镜像线路，也可在程序更新中切换。第三方镜像可用性因网络而异；程序始终校验发布签名和文件哈希，不接受被镜像修改的安装包。Android 首次安装更新需要按系统提示允许此应用安装软件，并由你确认更新。

## 后续整理与插件扩展

优先导出“结构化整理包”，其中含全部条目、字段定义、原文来源、图片与稳定的关联 ID。普通资料包是可直接读取的 JSON，不把正文藏进 HTML 或二进制中。

随包提供 `标准模板.json`、`资料包-schema.json`、`数据结构说明.json`。

电脑版运行后，本机 `http://localhost:17652/api/guide` 提供接口说明；认证信息在本机数据目录的 `connection.json` 中。外部整理工具应使用 `X-Starcase-Token`，不要展示密钥。先读取版本，再按稳定 ID 批量更新；版本冲突会拒绝覆盖。未认识的导入字段会保留，也能在编辑页的“其它导入字段”中修改。

## 当前验证范围

离线浏览器编辑、实际 Windows WebView2、本机 HTTP 保存与扫码传输、APK 签名和 Android 模拟器均有对应检查记录。没有实体手机相机对电脑二维码的现场验收。

软件由 AI 辅助编写；当前版本用于确认资料结构和操作方式，规则内容仍以你的原文和裁定为准。
